# CodiFork Test Docs

Fixture repository used by CodiFork's integration and E2E tests.

This repo holds a small set of markdown documents in `docs/` that the test suite
clones, edits, syncs, and opens PRs against. Treat anything in this repo as
disposable — tests rewrite history, force-push branches, and open/close PRs
against it constantly.

Do not put anything important here.
