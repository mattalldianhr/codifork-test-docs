# Onboarding PRD

## Problem

New users drop off before completing first-run setup. We need a guided onboarding
flow that walks them through connecting their first workspace.

## Goals

- Reduce time-to-first-document to under 5 minutes
- 80% of new signups complete the onboarding flow
- Surface the "add workspace" affordance within the first screen

## Non-goals

- Multi-tenant org provisioning (handled separately)
- SSO setup (deferred)

## Open questions

- Do we offer a sample workspace to play in, or require a real GitHub repo upfront?
